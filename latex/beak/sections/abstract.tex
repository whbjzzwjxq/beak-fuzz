\begin{abstract}

Zero-knowledge virtual machines (zkVMs) prove correct execution of RISC-V programs, but their security depends on faithful alignment between the RISC-V specification and the arithmetization that certifies an execution trace. When this alignment breaks, a prover can forge proofs for incorrect executions, undermining the trust model of systems securing billions of dollars. Detecting such \emph{semantic gaps} is challenging: each zkVM encodes its trace differently, and bugs cluster at rare invariant-critical conditions that are effectively unreachable by random testing.

Our key insight is that soundness bugs in zkVMs fall into two structurally distinct classes---executor \emph{divergences} (Type~I) and constraint \emph{underconstraints} (Type~II)---and that, despite heterogeneous internal representations, the \emph{invariant-critical conditions} that trigger both classes are shared across backends. We present \tool, a semantics-guided differential fuzzing framework that exploits this structure. \tool defines a \emph{cross-zkVM semantic model} that lifts six production backends into a common space of \tbd{39} semantic categories---\tbd{32} empirically derived from \tbd{25} audit findings and \tbd{11} prior dynamic-testing bugs, plus \tbd{7} structural categories enumerating the $2^n$-sized data structures mandated by STARK arithmetization (trace length, segment boundary, memory footprint, bytecode span, lookup volume, commitment length, and range-table utilization). On top of this model \tool runs a \emph{single invariant-targeted fuzzing loop} where category signature novelty replaces edge coverage as feedback, a multi-armed bandit governs \tbd{8} ISA-aware mutation strategies, and each category activation doubles as a targeting cue for semantic witness injection---transforming a blind $\sim$$10^8$-step witness search into a targeted $\sim$$64$-trial probe. Categories thus serve a dual role: the same coverage metric drives exploration \emph{and} localizes verifier-side bug detection.

Evaluated across OpenVM, SP1, RISC Zero, Jolt, Nexus, and Pico on \tbd{44} known vulnerabilities, \tool achieves \tbd{34/44} recall (\tbd{77.3\%}). On the four backends where the prior state-of-the-art (Arguzz) has full support, \tool detects \tbd{$1.5\times$} more bugs (\tbd{17 vs.\ 11}); across all six backends---including two for which Arguzz lacks backend adapters---\tool detects \tbd{34} vs.\ \tbd{11} bugs. \tool additionally discovers \tbd{6} previously unknown zero-day vulnerabilities including critical soundness violations in production systems. All findings have been responsibly disclosed and patched.

\end{abstract}
