# OpenVM Fuzzer Installer/Patcher (beak-py)

The default install root is repo-stable now and resolves to `beak-py/out/` instead of the caller's
`cwd`. Prefer `make openvm-install` from `beak-fuzz/`, or run the CLI from `beak-py/` directly.
